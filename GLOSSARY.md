# Glossary

Words this project uses. Agents should use these words and not swap in near-synonyms.

## The organisation

| Term                     | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Friends of Animals (FOA) | The non-profit this repo is for. The short form in the spec is FOA. The site name in code is the `SITE` object in `src/lib/site.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Registered logo          | The FOA mark. The vector master is `public/brand/foa-logo.svg`, traced from a screenshot. Use it as it is: scale it, never redraw, recolour, or rearrange it. Every other logo file is derived from the master by `pnpm brand:assets` (the derivations are in `scripts/brand-logo.ts`), and the app takes their paths from `SITE` (`src/lib/site.ts`). FOA answered issue #17 (closed): the three tiles may appear alone at icon sizes, and all-white and all-black versions are allowed. Whether the O tile may appear on its own is open in issue #23. `public/brand/README.md` lists the files. |

## How the work is tracked

| Term               | Meaning                                                                                                                                                                                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Wayfinder map      | GitHub issue #1, labelled `wayfinder:map`. It is the index of the platform effort: notes, decisions so far, and what is not specified yet.                                                                                                                                                                          |
| Wayfinder ticket   | A child issue of the map. The label says what kind of work it is: `wayfinder:research` (find out), `wayfinder:grilling` (the owner must decide), `wayfinder:task` (build something), `wayfinder:prototype` (a throwaway probe; the map currently says not to build throwaway UI).                                   |
| Decision           | The resolution comment on a closed wayfinder ticket, gisted with a link under "Decisions so far" on the map. Decisions live on GitHub issues, not in files. Issue #11 locked the stack.                                                                                                                             |
| Triage label       | One of `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`. A wayfinder label and a triage label answer different questions and can both be present.                                                                                                  |
| Ready for an agent | The issue is labelled `ready-for-agent`: specified well enough to carry out with no further questions.                                                                                                                                                                                                              |
| Ready for a human  | The issue is labelled `ready-for-human`: a person has to decide, sign, or use an account the agent does not have.                                                                                                                                                                                                   |
| The spec           | `specifications/SPEC.md`, assembled from the files in `specifications/parts/`; both come from FOA's brief, `specifications/FoA.md`. It is the one living spec, corrected in place: edit the parts, then regenerate `SPEC.md` from them. Its section numbers are stable. Issue #15 collects its open contradictions. |

## Environments and the database

| Term             | Meaning                                                                                                                                                                                                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP_ENV`        | Which deployment this is: `local`, `preview`, `staging` or `production` (SPEC §2.4). It defaults to `local`, and every Vercel environment must set it. Behaviour switches read it.                                                                                                                            |
| `APP_URL`        | The site's canonical base URL, used for absolute URLs such as Open Graph images. It defaults to `http://localhost:3000` locally and to the branch URL on a preview; staging and production must set it. Prerendered pages bake it in at build time.                                                           |
| Staging          | The test site, `shipped-it.dev`: the Vercel custom environment `staging`, which every push to `main` deploys, on the `foa_staging` database. Production deploys from the branch `production` instead and stays dormant until FOA's own domain arrives (SPEC §2.4).                                            |
| `DATABASE_URL`   | The app's runtime database connection. On Vercel it logs in to PgBouncer as an app role, which can only read and write rows and is pooled by transaction. The server won't start without it; `next build` doesn't need it.                                                                                    |
| `DIRECT_URL`     | The connection that `pnpm db:migrate` and drizzle-kit use. On Vercel it logs in to PgBouncer as a migrator role, which owns the schema and gets session mode, so the migration's advisory lock holds. Migrations never fall back to `DATABASE_URL`. Locally it is the same URL as `DATABASE_URL`.             |
| pg-prod          | The production Postgres server (Postgres 18.7 in Docker on the Mumbai VPS). It holds one database, `foa`, with point-in-time recovery.                                                                                                                                                                        |
| pg-nonprod       | The non-production Postgres server on the same VPS. It holds `foa_staging`, the `foa_seed` template, and the preview databases. No archiving, no point-in-time recovery.                                                                                                                                      |
| PgBouncer        | The connection pooler at `db.shipped-it.dev:6432`, the only public database endpoint: TLS and SCRAM, transaction pooling, session mode for the migrator roles. It sends database `foa` to pg-prod and every other name to pg-nonprod.                                                                         |
| Preview database | The database of one Vercel preview, on pg-nonprod: `foa_pr_<PR number>`, or `foa_br_<branch>_<hash>` before the branch has a PR. `pnpm db:migrate` creates it from the `foa_seed` template during the preview's build, and an hourly sweeper on the VPS drops it once the PR is closed or the branch deleted. |
| `foa_seed`       | The template database on pg-nonprod that every preview database is cloned from. Until a seed script exists it is empty, so previews start with the schema only.                                                                                                                                               |

## The platform spec

The spec's own names are canonical. This list is the ones people reach for first. The full set is in `specifications/SPEC.md`.

| Term                  | Meaning                                                                                                                                                                                                                     |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Platform              | The product described in `specifications/`: competitions for children and young people, then community, fundraising, and adoption facilitation. Milestones M0–M5 are the pilot. M6–M8 come after.                           |
| Milestone             | A named slice of the build, M0 through M8, in `specifications/parts/14-milestones.md`. M0 is foundations. The code today is the start of M0: a brand landing page, the site shell, the database layer and the test harness. |
| Competition           | A FOA creative contest (drawing, painting, art, craft, essay, photography, videography). Schools and individuals register, work is judged, certificates are issued.                                                         |
| Discipline            | One of those contest types: `DRAWING`, `PAINTING`, `ART`, `CRAFT`, `ESSAY`, `PHOTOGRAPHY`, `VIDEOGRAPHY`.                                                                                                                   |
| Institution           | A school, college, university, or other organisation that registers students. Not the same thing as FOA itself.                                                                                                             |
| Participant           | A young person who enters. A minor may have no login of their own; a guardian acts for them.                                                                                                                                |
| Guardian              | The parent or other adult responsible for a minor participant.                                                                                                                                                              |
| Registration          | One participant's place in one competition, with a registration number. Distinct from creating a website user account.                                                                                                      |
| Entry                 | One piece of submitted work, with an entry code and its own status (draft, submitted, shortlisted, and so on).                                                                                                              |
| Judging               | Scoring of entries. The spec has a school round and then an FOA round. FOA-round judging is blind: judges see the entry code, not the name, school or city.                                                                 |
| Certificate           | The document a registrant receives, with a number that can be checked. Not built.                                                                                                                                           |
| Donation              | Money given to FOA. Separate from competition fees. Not built.                                                                                                                                                              |
| Adoption facilitation | Helping people adopt animals that other organisations list. Milestone M7. The spec treats FOA as a facilitator, not as a shelter that keeps the animals. Not built.                                                         |

## Do not confuse these

| Say                                    | Do not say it when you mean                                              |
| -------------------------------------- | ------------------------------------------------------------------------ |
| `APP_ENV`                              | `VERCEL_ENV`, which reads `preview` in the `staging` custom environment. |
| `DIRECT_URL` (migrations, drizzle-kit) | `DATABASE_URL` (the app at runtime).                                     |
| Wayfinder ticket                       | A triage label. An issue can have both.                                  |
